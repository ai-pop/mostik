Первый публичный релиз.

Что внутри:
* `Mostik-win64.zip` — переносимая сборка для Windows 10/11 x64: сервис, окно управления, всё
  необходимое для работы. .NET устанавливать не нужно, OpenCode скачается автоматически.

Как начать:
1. Скачать архив ниже и распаковать в свою папку (не в `C:\Program Files`).
2. Запустить `Запустить Мостик.cmd`, подтвердить права администратора.
3. Войти через Discord — доступ открыт участникам нашего сообщества (ссылка-приглашение есть на
   экране входа; проверка обновляется автоматически, оффлайн-запас — 7 дней).
4. В окне скопировать Base URL (`http://127.0.0.1:4891/v1`) и API-ключ, указать их в своей программе.

Возможности: OpenAI-совместимый API (`/v1/chat/completions`, `/v1/models`), потоковая передача (SSE),
tool calling, алиасы привычных имён моделей на бесплатные модели OpenCode, автоустановка OpenCode,
локальная привязка к `127.0.0.1`, автогенерация ключа при первом запуске.

Полная инструкция, описание API и ответы на частые вопросы — в README.
