# Мостик 1.0.1

Исправление первого запуска Windows portable-сборки.

## Исправлено

* `Запустить Мостик.cmd` и `Остановить Мостик.cmd` сохранены с CRLF-окончаниями строк;
* добавлен `.gitattributes`, запрещающий возврат этой ошибки при следующих изменениях;
* обновлён архив `Mostik-win64.zip`.

## Установка

Скачайте `Mostik-win64.zip`, распакуйте его в папку, доступную для записи, и запустите
`Запустить Мостик.cmd`. Версия .NET отдельно не требуется.
