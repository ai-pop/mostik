# История версий

## 1.0.0 — 25.09.2026

Первый публичный релиз.

**Состав**
* сервис `opencode-openai-bridge.exe` — локальный API в формате OpenAI;
* окно управления `opencode-bridge-ui.exe` — Панель, Чат, Модели, Логи, Настройки;
* всё необходимое для работы внутри архива: .NET устанавливать не нужно.

**Возможности**
* `POST /v1/chat/completions` в обычном режиме и потоком (SSE), `GET /v1/models`, `/healthz`;
* tool calling (`tools`, `functions`, `tool_calls`, `tool_choice`);
* «размышления» модели отдельным полем `reasoning_content`;
* алиасы привычных имён моделей (`gpt-4o`, `gpt-4o-mini`, …) на бесплатные модели OpenCode;
* автоустановка OpenCode при первом запуске;
* старт/стоп/рестарт сервиса из окна, живые логи, правка конфига;
* локальная привязка к `127.0.0.1`, автогенерация API-ключа при первом запуске;
* переносимая сборка: папку можно положить куда угодно и запускать одним файлом.
