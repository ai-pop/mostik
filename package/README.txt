МОСТИК - локальный AI-API (формат OpenAI)
=========================================

Быстрый старт
-------------
1. Запустите "Запустить Мостик.cmd"
2. Windows один раз спросит права администратора - нажмите "Да"
3. В окне "Мостик" блок "Подключение клиентов": скопируйте Base URL и API-ключ
4. Укажите эти адрес и ключ в своей программе

   Base URL:  http://127.0.0.1:4891/v1
   API key:   показан в окне (кнопка "Копировать")
   Модель:    big-pickle

Проверка: в окне откройте "Чат" и напишите "привет".

Требования: Windows 10/11 64-бит, интернет.
Ставить .NET и OpenCode не нужно - всё внутри, OpenCode скачается сам.

Остановить: "Остановить Мостик.cmd"

Полная инструкция, ответы на вопросы и описание API: README.md в корне архива
(и на странице проекта в GitHub).
